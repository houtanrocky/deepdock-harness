## Detailed description

DeepDock Harness adds a coding-agent panel to DeepSeek Chat. Connect it to the DeepDock Harness Bridge on your computer to let a DeepSeek conversation work with a project folder using local file, search, shell, Git, and GitHub tools.

You choose the workspace folder and how much approval the agent needs. Review sensitive actions, stop a task while it runs, and resume an unfinished task after a page reload. DeepDock Harness saves conversation checkpoints in your browser so work can recover without silently repeating a tool action.

Getting started:
1. Install the DeepDock Harness Bridge for Windows and choose a project folder.
2. Paste the pairing token copied by the bridge installer into DeepDock Harness Settings.
3. Open chat.deepseek.com, test the bridge connection, and enable the agent for a conversation.

DeepDock Harness only adds its panel on chat.deepseek.com. It sends requests to the local bridge at 127.0.0.1; it does not send project files or chat history to a DeepDock Harness-operated server. Prompts and relevant conversation context are sent to DeepSeek through the normal chat interface so DeepSeek can perform the requested task. If you use GitHub tools, those operations use your local GitHub CLI authentication and communicate with GitHub.

The bridge is a separate install. The current companion installer targets Windows x64. DeepSeek account access and model availability are provided by DeepSeek and are not included with DeepDock Harness.

## Single purpose statement

DeepDock Harness turns a conversation on DeepSeek Chat into a user-controlled coding agent by connecting that conversation to local project tools through a separately installed loopback bridge.
