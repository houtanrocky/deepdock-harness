## Detailed description

Give DeepSeek Chat the tools to work on your local project.

DeepDock Harness adds a coding-agent panel beside your DeepSeek conversation. Connect it to the companion bridge on your computer, choose a project folder, and let the chat read files, make focused edits, run checks, and work with Git and GitHub. Follow each step in the panel and choose when the agent needs your approval.

WHAT YOU CAN DO

- Explore a project: browse folders, read files, and search source code without manually pasting every file into chat.
- Make focused changes: write and edit files, then inspect recorded before-and-after diffs.
- Check the result: run local commands and review their output alongside the task.
- Work with Git and GitHub: inspect changes, stage files, commit, configure a remote, and publish to an explicit repository using your existing authentication.
- Keep track of the task: see tool explanations, results, errors, changed files, and the remaining iteration budget.
- Continue unfinished work: saved conversation checkpoints let you explicitly resume after a reload. Requests with uncertain outcomes pause for review rather than silently replaying changes.
- Optionally hand off a self-contained plan to a separately installed local DeepSeek Harness agent.

PERMISSIONS YOU CONTROL

Choose Ask for important commands, Ask every time, or Full access. Allow a requested action once, deny it, or stop a running task. The saved permission mode controls execution; the model cannot change that setting through its tool arguments.

Direct file tools validate configured workspace paths. Full access permits unrestricted shell commands, and an optional local agent uses its own execution policy. Choose the mode to suit your project and review the workspace after an interrupted operation.

GET STARTED

1. Install the companion Windows bridge from the project website and choose a project folder.
2. Copy its local pairing token into the extension's Settings.
3. Open chat.deepseek.com and select Test connection, then Enable agent.
4. Send a task in DeepSeek's normal chat composer. Start with a small read-only task, then try a focused edit and a check.

The bridge is a separate installation and currently targets Windows x64. A DeepSeek account and access to DeepSeek Chat are required. Git features require Git; GitHub features use your existing Git and GitHub CLI authentication. Optional agent handoff requires its own runtime and provider credentials.

DATA AND PRIVACY

Tools run on your computer through an authenticated bridge at 127.0.0.1. Relevant prompts, source text, and tool results can be sent through your normal DeepSeek Chat conversation and are handled under DeepSeek's terms. Settings and task checkpoints are saved in your browser. The project operates no collection server and includes no analytics.

When you use the GitHub account-status tool, its result includes the active GitHub username. That account identifier can appear in saved task results and relevant follow-up prompts.
